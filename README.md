One funny single line a hopeless tech support agent says to a desperate customer, for the [Have You Tried Turning It Off?](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b) bounty on make.fun.

## Entry

> Your files are safe in the cloud — which is great, because I have absolutely no idea where the cloud is either.

The agent cheerfully reassures the customer, then admits he has no idea where the cloud is either. The agent is the butt of the joke, never the customer.

## How it works

`main.py` is deterministic (no network, no randomness, no clock). It validates the entry — UTF-8, 1–199 characters, not only whitespace, a single line — and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
